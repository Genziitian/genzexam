Questions people ask first.

Which programmes and terms do you cover?

All four IITM BS programmes — Data Science and Applications, Electronic Systems, Aerospace Engineering, and Management and Data Science — across Qualifier, Foundation, Diploma and Degree levels. Within each, you will find Quiz 1, Quiz 2, End Term, mock tests and practice sets. New papers are added as each term's papers are released.

Is this the same as the real exam portal?

It is built to behave like it: the same one-question-at-a-time layout, question palette, mark-for-review, Save & Next flow, calculator, and the same marking rules including negative marking. It is a practice environment, not the institute's portal, and sitting a paper here has no bearing on your actual results.

Can I practise without a timer?

Yes. Practice mode has no clock — choose an option and the correct answer and worked solution appear straight away, so you can work through a paper question by question. Exam mode is the timed version with solutions held back until you submit.

Does it work offline, or on a phone?

The Android app can download a paper to your device and you can sit it with no connection; it syncs when you are back online. The website works on a phone for browsing and practice. Invigilated proctored exams are laptop and desktop only, because the monitoring the browser provides is not available on mobile.

What happens if my connection drops mid-paper?

Answers save to the server as you go, and the page tells you plainly whether your latest answer is saved. If a save fails it keeps retrying and you can force one with Save now. Refreshing recovers everything the server has. Because the clock runs server-side, a disconnection does not pause it.

How are short and numerical answers marked?

Numerical questions accept an absolute tolerance set per question. Short answers are matched case-insensitively against the accepted answers after trimming whitespace. Multiple-select questions need the exact set of options — partial credit is not awarded. Blank questions score zero rather than a penalty.

Can I delete my account and data?

Yes. You can request deletion from the account deletion page or in the app. Where exam records have to be retained — for instance an invigilated exam you sat for an institution — we deactivate the account instead and tell you why, rather than destroying records someone else depends on.
